ADR Autopsies: fact-checking architecture decisions

Every project writes Architecture Decision Records. Almost nobody checks whether the architecture actually did what the ADR promised. We run arcade-agent on both sides of the implementing PR and grade each claim: CONFIRMED / PARTIAL / REFUTED / UNVERIFIABLE. Method: reproducible scripts.
