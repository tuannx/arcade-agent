# ADR-0001: Evidence before visualization

Status: Proposed

## Decision
Extend arcade-agent incrementally. Keep analysis core independent of GitHub, UI and LLM adapters. Use a canonical evidence graph with provenance. Treat package-based recovery and smell detection as hypotheses, not architectural truth.

## Alternatives
- Clone PGSimCity UX: rejected for MVP; visual fidelity does not establish correctness.
- LLM-only architecture review: rejected; hard to reproduce and verify.
- New analysis engine: deferred; reuse existing code and benchmark gaps first.

## Consequences
+ Deterministic CI and explainable findings.
+ Reusable across CLI, PR, MCP and UI.
- Framework-specific semantics require adapters.
- Runtime behavior needs separate verification.
- No trustworthy what-if predictions without explicit assumptions and measured evidence.
