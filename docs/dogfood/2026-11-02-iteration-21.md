## Concrete bug and smallest regression

At **module scope**, `import json as helper` binds `helper`, not `json`. The Python graph linker incorrectly added `json` to the shadowing set, permitting a false direct `calls` edge to a same-module `def helper()`. Likewise, it tested the source module basename rather than the actual imported alias when deciding whether to create an `import` edge to an analyzed module entity.

Small fix: record `aliases[module] = alias` only for aliased module imports and use the actual bound name both for module-import use detection and same-module call shadowing. For an unaliased `import pkg.sub`, use the bound root `pkg`. Imported names in `from pkg import name` retain the prior resolution path; local import binding logic from PR #30 is unchanged.

The five hand-labelled tests are in `tests/test_parsers/test_python_module_import_aliases_dogfood.py`:
- Three **negative call-label cases**: plain alias, dotted alias, multi-import alias. Before the fix each produced one *spurious* same-module `calls` edge; after the fix all three are absent.
- One **positive call-label control**: an unrelated module alias does not suppress the valid `parent -> helper` call (kept).
- One **positive import-label case**: `import pkg.sub as gateway` referencing `gateway.VERSION` must link to the parsed `pkg.sub` module entity (previously missed, now present).

**Test-first RED:** [hosted CI 41419809382](https://github.com/tuannx/arcade-agent/actions/runs/41419809382) on test-only commit `42fb19fc...`. Python 3.12 reported **4 failed / 894 passed / 3 skipped**. Python 3.13 also logged those four failing tests but its job conclusion was **cancelled by fail-fast**: it is not claimed to have completed normally.

**GREEN:** [CI 41419930778](https://github.com/tuannx/arcade-agent/actions/runs/41419930778) on implementation SHA `82772a66...`: **898 passed / 3 skipped on Python 3.12**, **898 passed / 3 skipped on Python 3.13**; analysis and package jobs passed. `pytest -q tests/test_parsers/test_python_module_import_aliases_dogfood.py` is the focused test command; the hosted full suite runs the repository CI test commands.

This is **three removed false edges and one recovered true import edge in a deliberately selected fixture**, NOT a population false-positive rate, production precision/recall improvement, or a verified architecture violation. `python.call_coverage` stays `partial`.
