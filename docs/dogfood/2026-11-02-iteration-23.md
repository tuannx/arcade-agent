## Bug and selected truth labels

Old linker would confidently link `class Child(wire.Base)` to `pkg.base.Base` even after `wire = alternate` rebound that name to `pkg.other`. It similarly reported an incorrect `extends` edge after an imported class alias or same-module class declaration was reassigned.

Fix: retain an **ordered snapshot of direct top-level bindings at each class definition**; if the last binding of its superclass name is an assignment, do **not** assert a stale inheritance edge. Imports and declarations reset that assignment marker; a later assignment does not retroactively change earlier class inheritance. Cache extraction version `4 → 5` and full-graph cache schema `9 → 10` prevent old facts/graphs being reused.
