## Commands, tests and actual artifacts

The cross-repo workflow runs commands equivalent to:

~~~bash
git -C analyzer rev-parse HEAD
git -C target-java rev-parse HEAD
arcade-self-analysis --source target-java --language java \
  --repo-name tuannx/spring-boot-multi-region-ha \
  --expected-source-sha 5a4ba4d33dfd88a90fd6ec749894fd0088baf1d9 \
  --analyzer-source analyzer --expected-analyzer-sha "$(git -C analyzer rev-parse HEAD)" \
  --output-json java-ha-analysis.json --output-html java-ha-report.html
~~~

## Trade-offs / blockers / next action

Analyzer attestation only compares the checked-out Python package bytes against the installed package; it does not attest third-party/native dependencies, ignored files, concurrent mutations, or that every reported architecture edge is semantically correct. The Java, private Python and examples graph totals are unchanged at identical source SHAs; there is **no production precision/recall, false-positive rate or source architecture improvement claim**. Low-coverage heuristics are advisory, never verified violations.
