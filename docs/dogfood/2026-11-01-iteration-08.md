# Iteration 08 — Conservative Python local calls (2026-11-01)

## Change
Dogfood of `arcade-agent` exposed a documented gap: Python parsed imports
and inheritance, but did not collect calls. Add conservative `calls` edges
only for **unqualified calls to top-level functions defined in the same
module**, excluding locally shadowed, module-rebound, and imported names.
Nested scopes, method/attribute dispatch and dynamic calls remain unresolved.
Declare `call_coverage: partial`, **not complete**, so low-severity
insufficient-evidence warnings remain non-scoring. Cache format version 3 -> 4
prevents stale extracted facts.
