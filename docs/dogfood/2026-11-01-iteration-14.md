## Change and labelled ground truth

The Python bare-call extractor previously removed *real* module-function call edges when:
1. A function used `global helper` to refer to module-level `helper()`.
2. Another parameter had an annotation referencing the same function, e.g. `def caller(value: helper): return helper()`.
3. Another parameter's default value referenced that function, e.g. `def caller(value=helper): return helper()`.

These are **false negatives in call-edge extraction**, not verified architecture violations. Fixed by excluding `global_statement` from local shadowing and extracting formal parameter bindings without descending into annotation/default expressions. Kept real local assignments and formal parameter names as negative controls. Python call coverage remains **partial**; attribute dispatch, dynamic names and closures are not claimed complete.

Golden fixture: `tests/test_parsers/test_python_global_parameter_dogfood.py`, containing **three positive expected edges and three negative-control call locations**. This is a small labelled corpus, not a representative precision/recall benchmark. No population-level false-positive or false-negative rate can be inferred.
