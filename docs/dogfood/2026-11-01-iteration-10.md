# Iteration 10 — Independently attested analyzer-source provenance (2026-11-01)

## Scope and exact identity

The preceding private Python HA workflow set `GITHUB_SHA` to the analyzer's
checkout SHA to work around a mismatch between **host** CI SHA and **executed**
analyzer SHA. This iteration replaces that workaround with explicit
`--analyzer-source` and `--expected-analyzer-sha`. The CLI now requires a
clean pinned Git checkout and byte-for-byte equality of checkout
`src/arcade_agent/**/*.py` files and the imported Python package. If not
supplied, analyzer SHA is `unavailable`, not host SHA.
